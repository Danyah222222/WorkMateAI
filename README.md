# WorkMate AI

WorkMate AI is an AI-powered workplace assistant designed to help employees access company information, manage tasks, and interact with internal services from one platform.

## Features

- AI-powered workplace assistant
- Company knowledge and document search
- Employee directory
- Project and task management
- HR leave requests
- IT support tickets
- Role-based access control
- Secure multi-company workspace isolation

## Tech Stack

**Frontend:** React, Tailwind CSS, Shadcn/UI  
**Backend:** FastAPI, Python  
**Database:** MongoDB  
**AI:** AI assistant with tool-based capabilities

## User Roles

Owner • Admin • Manager • Employee
